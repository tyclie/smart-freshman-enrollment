# 智慧迎新系统优化方案

## 一、3D 校园模块优化

原 3D 页面主要问题：

1. 依赖两个不同来源的旧版 Three.js CDN，且 `examples/js` 脚本与 `r128` 主库混用，容易加载失败，导致页面一片空白、看不到模型。
2. 3D 坐标中心写死为北京坐标（`116.3075, 39.9945`），但校园导航数据实际位于校园所在城市（`115.0x, 30.2x`），建筑被换算到很远的位置，即使引擎正常也可能看不到模型。
3. 建筑全部是随机尺寸的立方体，缺少门窗、屋顶、道路、绿化和交互反馈，视觉粗糙。

本次修改：

- 将 Three.js、OrbitControls、CSS2DRenderer 下载到本地 `static/js/vendor`，不再依赖 CDN。
- 改为从 `/api/campus` 动态获取与导航一致的校园地点，自动计算中心点并按米制坐标放置建筑。
- 按建筑类型生成差异化模型：校门、教学楼、图书馆、食堂、宿舍楼、体育馆、行政楼、智慧大楼。
- 增加地面、道路网、中央喷泉、随机绿化、阴影、雾效与标签。
- 增加点击查看详情、高亮建筑、视角复位、路线开关、标签开关、日夜切换、自动漫游、地点搜索、WASD 移动。
- 增加加载中、加载失败、加载超时的用户可读提示。

## 二、系统页面与功能优化

- 统一所有后台页面的导航栏，并增加移动端汉堡菜单。
- 新增全局 `app.js`，统一提供 Toast 消息、安全转义、请求封装。
- 登录页优化：渐变品牌区、演示账号快捷填充、密码显示/隐藏。
- 智能填报：自动预填当前学号，改为非阻塞 Toast 提示。
- 主面板：修复“已选宿舍信息”因后端查询缺字段而始终不显示的问题。
- 辅导员后台：修复演示账号 `cs1` 查不到“软件工程1班”学生的问题，并显示正确班级名。
- 宿舍选择：修复换床位时旧床位未释放的问题；选择后不会把已完成流程倒退。
- 聊天室：对消息内容做 HTML 转义，避免脚本注入。
